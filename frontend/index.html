Project Observation

Main Bottleneck: Data Loading

The benchmark shows that data loading and CSV parsing take most of the total execution time. The sequential loading time was approximately 16.9270 seconds, while the actual computation took only 0.0309 seconds. Therefore, approximately 99.82% of the measured sequential execution time is associated with loading and parsing.

This explains why the computation speedup reaches 5.52x at 8 threads, while the overall execution speedup is only about 1.02x.
